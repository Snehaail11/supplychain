# Supply Chain Dashboard (Power BI)

This project focuses on analyzing supply chain performance using real-world logistics data. The dashboard provides a clear overview of operations across regions, helping identify delays, optimize inventory, and make faster decisions.

## Why I Built This

Supply chain issues impact businesses every day, and I wanted to build something that made those issues easier to track and understand. I worked with a large dataset to transform raw logistics information into visual insights using Power BI.

## Key Features

- **Regional Performance**: Compare key KPIs like orders processed, delivery time, and costs across different regions.
- **Inventory & Fulfillment**: Track fulfillment rate, inventory turnover, and shipment delays.
- **Product Category Breakdown**: See which categories are driving performance or causing bottlenecks.
- **Filters**: Easily filter by date, region, product category, and shipping mode.
- **Trend Analysis**: Line charts to spot delays or cost changes over time.

## Tools & Skills Used

- **Power BI** – for visualization, DAX calculations, and dashboard building.
- **Excel** – for initial data preparation and cleanup.
- **Data Cleaning** – handled nulls, duplicates, and inconsistencies.
- **DAX** – created custom measures and calculated columns.
- **Business Analysis** – focused on KPIs that matter to supply chain managers.
